# Battle Arena — Community Event Website

A free, responsive, original gaming-event landing page inspired by modern mobile battle-royale event aesthetics.

## Files
- `index.html` — main page
- `style.css` — responsive styling and animations/effects
- `script.js` — reward modal interactions

## Run
Open `index.html` in any modern browser.

## Publish for free
You can upload these files to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
